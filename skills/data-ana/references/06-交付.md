# 06 · 交付

链路第 7 步。数字已经算对了，这一步只决定「怎么让人看懂」。

## 一、先判断该不该出图

**数据支撑不了 3 个以上有信号维度，就不要出图。** 硬画图会误导。

五种情况直接说不：

| 情况 | 怎么办 |
| --- | --- |
| 有信号的维度不足 3 个 | 「这份数据更适合附表，硬画图会误导」 |
| 零方差列占比过半 | 直接说哪几列无图可出 |
| 用户要精确数字对比 | 给表格，图只做趋势辅助 |
| 类目 > 8 且无稳定含义 | 合并类目或换表格 |
| 样本量太小（n < 30） | 图上标注，并明确说「仅供参考」 |

## 二、图型选型

按数据形状分流，而不是按「哪个好看」。

```
数据形状是什么？
├─ 连续时间序列
│   ├─ 单序列，≤ 40 期        → 折线 / 面积
│   └─ 单序列，> 40 期        → 面积（折线太密看不清单点）
├─ 离散类目
│   ├─ 类目 ≤ 12 且名短       → 柱状（可堆叠）
│   ├─ 类目多或名长           → 横向条形
│   └─ 构成占比              → 堆叠柱 / 环形（≤ 6 类）
├─ 两连续变量                → 散点
├─ 多群体 × 两指标            → 哑铃（Excel 里难做，见下）
├─ 多维评分（≤ 6 维）         → 雷达
├─ 两离散维度交叉            → 热力（Excel 用条件格式色阶代替）
└─ 增减分解                  → 瀑布（用堆叠柱模拟）
```

**兜底：形状不属于以上任一类，就退回表格。不要硬凑图型。**

## 三、按问题选图（示例）

| 要回答的问题 | 该用什么 | 红线 |
| --- | --- | --- |
| 总量从 A 变到 B，各因素各贡献多少 | 瀑布（堆叠柱模拟） | **步序按业务因果排，不能按大小排** |
| 同一对象前后两个时点的对比 | 哑铃；Excel 难做则用并排柱或表格 | 图例写清哪个点是什么 |
| 各责任人的贡献排名 | 横向条形 | 首位用最深色 |
| 两个连续量的分布关系 | 散点 | **图注必须写「相关不等于因果」** |
| 各分类的规模 | 柱状 + 数据标签 | 类目 ≤ 4，不需要图例 |

## 四、openpyxl 的能力边界

`openpyxl.chart` 原生支持柱状、条形、折线、面积、饼图、散点、雷达、气泡。
**不支持瀑布图和哑铃图**，只能用近似方案：

| 想要的图 | Excel 里的做法 | 代价 |
| --- | --- | --- |
| 瀑布 | 堆叠柱：底层柱设透明（`noFill`）当占位，上层柱显示增量 | 需要多两列辅助数据，图例要处理掉透明系列 |
| 哑铃 | 两条并排柱，或直接退回表格 | 丢了「两端对比」的直观性 |
| 热力 | 条件格式色阶（`ColorScaleRule`）+ 数值文本 | 不是真图表，不能导出为图片 |

**如果某个图需要三种以上近似手段才能凑出来，就退回表格。** 这是选型兜底原则在实现层的延伸。

## 五、报告结构

固定五个工作表，缺一个看报告的人就要多问一句：

| 工作表 | 作用 |
| --- | --- |
| 运行摘要 | 这轮用了哪版数据、跑了多少行、各档多少——不打开明细也知道结果 |
| 报告 | 逐项明细，按优先级排序 |
| 月度数据 | 中间结果，供复核 |
| 规则说明 | 每条口径一句话解释，**从常量区生成，不手写** |
| 图表 | 3–5 张，每张配一句「阅读方式」 |

### 口径必须披露

报告里必须能回答三个问题：

1. 这版数据是什么时点的？（数据归档日 / 数据覆盖月份）
2. 因为口径少了多少？（排除行数、排除金额）
3. 这个数字算不出来时是什么意思？（`NaN` 的含义、`0` 的含义）

**缺失、异常、清洗、过滤、降级，全部要披露。** 不披露的过滤等于数据无声消失。

## 六、文案

| 要求 | 反例 |
| --- | --- |
| 标题写结论，不写名词 | 「七月流量爆发」优于「月度流量」 |
| 图注写清「一个单位代表什么」 | 「每根细线代表 X」 |
| 不用内部行话 | 页面上写「细线」「点」，不写函数名 |
| 不写全大写英文脚注 | 读者可能完全不懂英文 |

## 七、门禁

- [ ] 每张图对应一个明确问题，不是「有数据就画」
- [ ] 支撑不了 3 个信号维度已经退回表格
- [ ] 图例/图注写清了一个单位代表什么
- [ ] 散点图注写了「相关不等于因果」
- [ ] 瀑布步序按业务因果排
- [ ] 规则说明从常量区生成，未手写
- [ ] 数据时点、排除量、空值含义三件事都披露了
- [ ] 图表与正文数字一致
