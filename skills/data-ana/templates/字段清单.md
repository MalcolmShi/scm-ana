# 字段清单模板

字段盘点是清洗的第一步，产出物是每个字段一行。

## 列的填写要求

| 列 | 填写要求 | 常见错误 |
| --- | --- | --- |
| 字段 | 原始列名，不改写 | 用清洗后的名字 |
| 类型 | pandas dtype | 写「数值」「文本」这类模糊说法 |
| 唯一值 | `nunique(dropna=True)` | 把空值算进唯一值 |
| 非空率 | `notna().mean()`，保留两位小数 | 用「有值行数」代替比例 |
| 说明 | 这列是什么、单位、取值域 | 复述列名（「销售额：销售的金额」，等于没说） |

## 分组

按业务语义分组，不要按字母序或原表顺序。分组名要稳定，后续文档和代码都引用它。

参考分组（按业务语义定，随项目变化）：时间 / 组织 / 单据 / 对象 / 分类 / 交易对方 / 数量与金额 / 元数据。

## 必做的三件事

1. **统计口径要写明**：用哪段数据算的唯一值和非空率（例：2026-09 单月，共 <N> 行）。
2. **异常字段加粗标注**：空值率高、取值脏、语义混装的，在说明里直接点出来，不要留给读者自己发现。
3. **与代码保持一致**：分组常量放在来源模块里，文档表格顺序与之一致。
