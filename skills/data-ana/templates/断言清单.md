# 断言清单模板

断言是清洗的验收条件。没有断言的清洗，等于没有验收。

> 四类断言的划分对所有来源不变；示例里的 `<字段>` 按你的来源替换。

## 四类断言

| 类型 | 作用 | 例子 |
| --- | --- | --- |
| 勾稽 | 字段间算术关系成立 | `单价 × 数量 = 金额` |
| 守恒 | 聚合值前后一致或差异可解释 | 清洗前后金额合计 |
| 值域 | 枚举字段只在合法集合内 | `状态 ∈ {生效, 失效}` |
| 唯一性 | 主键或组合键不重复 | `单据号 + 明细行号` |

每个来源**至少两条**：一条勾稽 + 一条守恒。

## 写法

必须是能直接跑的表达式，不要写成自然语言描述。

```python
# 勾稽：单价与数量都非空的行应逐行成立。
# 单价为空 = 该行「不适用」（如退货行），不进本断言。
# 不要 fillna(0) 凑数——那会把「不适用」伪装成「单价为 0」，污染通过率（见 03 的符号原则）。
mask = clean["<单价>"].notna() & clean["<数量>"].notna()
calc = clean.loc[mask, "<单价>"] * clean.loc[mask, "<数量>"]
ok = (calc - clean.loc[mask, "<金额>"]).abs().le(<容差>)
print(f"{ok.sum():,} / {mask.sum():,} = {ok.mean():.2%}")
assert ok.all()

# 守恒：去重前后差异必须显式记录
before, after = df["<金额>"].sum(), clean["<金额>"].sum()
assert abs(before - after) < <预期差异>, f"差异 {before - after:.2f} 未解释"
```

## 容差

- 金额：取业务上可忽略的最小单位（例：0.01 万元）
- 单价：`1e-6`
- 浮点相等一律用 `abs(a - b) <= tol`，不要用 `==`

## 失败时怎么办

断言失败不是「调整容差」，而是说明规则漏了一种情况。回去补口径识别，不要放宽标准。
