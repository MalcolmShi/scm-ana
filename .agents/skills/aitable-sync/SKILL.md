# 采购业务多维表同步

先识别本次业务，再读取对应资料；两项业务可以共用入口，但数据、表和负责人规则独立。

- **采购增量识别及任务跟踪**：读取 [references/procurement-increment.md](references/procurement-increment.md)。其中有已建表配置、导出字段、人员映射和更新规则。
- **采购降本填报、初稿复核和反馈**：读取 [references/procurement-savings.md](references/procurement-savings.md)。其中有各业务的数据、双向流向和待确认的建表事项。

按用户指定的业务和目标准备数据；需实际操作钉钉多维表时，使用环境中的 `dingtalk-aitable` 技能及其工具核对字段和执行。人员字段使用同一钉钉组织下的真实 `userId`；根据实际工具契约组装写入值，不将姓名或单独的 ID 当作完整的人员字段请求。组织信息由连接钉钉的执行环境处理，不要求用户额外提供。

核对数据来源、目标表及同步方向；更新已有记录时保留采购员维护的反馈和修正。写后回读核对；写入结果未知时先对账，不盲目重放。本地准备、模拟或规划不代表已经推送或实现自动同步。
