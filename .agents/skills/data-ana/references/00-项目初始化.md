# 第零步：项目初始化

只补当前任务缺少的环境和模块，不重复初始化已有项目。

- 使用 `uv sync` 复用环境；缺少的依赖按用途添加到 `pyproject.toml`。
- `src/` 按来源接入、清洗、分析、读写和服务划分；`scripts/` 串联流程。
- `notebooks/数据清洗/` 保存共享数据集的确认记录；场景目录保存方案和指标验证。
- DuckDB 位于 `data/scm.duckdb`，按 raw、processed、outputs 分层。不要为了初始化创建空数据或假定数据源已经接入。
- 确认分层读取接口可用：`read_raw_<来源>()`、`read_processed_<数据集>()`、`read_outputs()`；缺少时按实际数据集实现，不自动换层。
- 检查依赖和相关测试；无真实数据时用临时数据库验证读写，不修改业务数据。

完成后按当前业务任务进入相应步骤。来源接入与分析命令以实际代码为准。
