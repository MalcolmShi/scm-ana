# 第四步：指标验证与稳定脚本

> 产出：分析方案.md 的「四、指标验证与稳定脚本」+ 指标验证 notebook
> （模板：`templates/指标验证模版.ipynb`）+ 稳定指标脚本 + outputs 归档。
> 输入是第三步已归档的 processed，本步不重放清洗。读取、归档及模块职责以
> [数据与代码约定](数据与代码约定.md) 为准；下方接口示例需先核对或补齐实现。

## 怎么做

1. **显式读 processed**：取数单元格只导入读取函数、指定窗口并读取 `df`；用 `read_processed_<数据集>()`，正式复跑用对应 `*_meta()` 留痕。
   声明依赖的数据集、schema/规则版本和窗口；由读取层或正式入口校验必需字段、类型、粒度与覆盖，
   不把工程校验堆进 notebook 取数格。缺字段、缺档或过期要明确失败；覆盖无法确认时标为待核实，
   可做标明局限的探索，不能宣称正式验证完成；不能退回 raw、静默跳过或在本步补洗。
   来源标准有问题回第三步，场景业务过滤和衍生计算保留在分析层。
2. **逐步展开 dataframe**：按方案中的时间、金额和范围等条件，从 `df` 生成并展示通过条件的 `df1`；
   后续基于 `df1` 计算并展示指标，独立指标可以并行，需要月度基础数据的指标引用同一份月度结果。
   过滤后的 `df1` 保留全部输入字段、重点列前置；展示指标时可将指标关联回 `df1`，让业务看到完整上下文。
   区分逐笔展示与聚合结果，补零月份保留在月度表，不能伪造对应原始明细。
   最后按确认的粒度与周期合并为一张候选报表。需要核对被剔除的记录时，再筛选并展示剔除明细，
   不强制每一步都先展示剔除项。每节简述口径、公式与实际数量，不用 head/tail/sample 代替完整明细。
3. **先声明粒度**：一行代表什么、键是什么、金额单位和税口径、空值与零分别表示什么、能否跨维度加总。
   一对多 join、重分摊或加权指标单独说明，不能直接对百分比求和。
4. **对账三件套**：
   - 对业务已知数：引用 1.3 的参考报表与条件，差异定位到口径或数据。
   - 对明细：选定有定位条件的业务记录手工复算；完整明细仍保留。
   - 对总账：明细 → 分组 → 总计逐层核对；有期初期末的再做首尾勾稽。
   数值使用业务确认的精度/容差，先比原始值再格式化；空值不能用零掩盖。
5. **差异查到根因再继续**：数据错误回第二/三步；指标口径错误回 1.4，并在 4.2 记录修改、原因和确认。
   参考数有问题也要有可复核证据，不能只补一句解释。
6. **按真实报表逐张确认输出**：完整结果以命名 dataframe 供翻查，每张记
   表名 / 粒度与键 / 字段及单位口径 / 更新方式 / 看板用途 / DuckDB 表名，写入 4.3。
   归档周期、周期边界和归档日期若尚未明确，先询问用户；已经确认的不重复询问。
   业务要求展示全部来源字段时，重点字段前置，其余字段保留在后；汇总粒度下同一键有多个取值时，
   保留所有不同取值并说明其含义，不能静默取首值；逐笔字段间的对应关系通过输入明细核对。
   预览可用标量或列表；正式归档前为每列确定一致的类型（必要时统一列表或拆分明细表），
   并验证数据库结果可读回，不能把不同记录的值误认为逐笔对应。
   主表统一键为 `detail`；其他表的名字与 JSON `tables` 键、文件清单一致。
   月度趋势、分组汇总若是确认结果表，也必须有独立结果表。
7. **确认后沉淀指标脚本**：
   - 分析函数显式接收 processed dataframe 与配置，多来源输入分别声明；返回命名结果表与元数据。
   - 可变窗口、阈值进参数，稳定业务常量命名表达；不复制来源清洗逻辑，不在函数内隐式取数或导出文件。
   - 入口脚本按场景命名，串联读取、分析、校验、归档；最终报表可消费同次结果导出 Excel。
   - 合成数据验证指标边界、分层加总，以及真实清洗输出能进入分析的衔接；不只测彼此隔离的函数。
8. **归档所有确认表**：多表在一次事务中写入 DuckDB，记录归档日期和输入指纹；路径和元数据按 [数据与代码约定](数据与代码约定.md)。缺少能力先补实现并验证，再运行归档。
9. **从指定业务周期读回对拍**：
   - 用 `read_outputs(场景, 业务结束日, table=表名)`，逐张对比 notebook、脚本与数据库。
   - 对比表集合、列名、行数、空值及全部指标值，不靠金额总和相等替代明细一致。
   - 实际计算差异并断言，报表中的舍入只用于展示；同时核对 元数据中的输入版本、参数和归档日期。
